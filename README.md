# Open-dyslexic

An Android custom keyboard project focused on making the keyboard's own key labels use the OpenDyslexic typeface.

## Project scope

- Android custom keyboard implemented with `InputMethodService`
- OpenDyslexic typography for keyboard key labels
- Letter, number, and symbol layouts
- Adjustable key size and spacing
- Light and dark themes
- Long-press alternate characters
- Suggestions and autocorrection
- Emoji and clipboard panels
- Lightweight operation, with the Samsung Galaxy A05 as the baseline test device

**Font scope:** OpenDyslexic is used inside the keyboard UI. Text entered into another app continues to use that app's own font; this keyboard does not change system-wide or other-app typography.
