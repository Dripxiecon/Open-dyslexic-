# Testing checklist

- Confirm the keyboard appears in Android Settings > General management > Keyboard list and default.
- Enable it manually; Android requires the user to approve and select third-party keyboards.
- Test typing, deletion, space, and enter in a plain text field.
- Test secure/password fields: Android may choose another input method for security.
- Test portrait and landscape orientation.
- Check that no typed text is stored or transmitted by this initial scaffold.
- Run on the Galaxy A05 and record startup time, keyboard height, and responsiveness.
