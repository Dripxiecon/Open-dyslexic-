# OpenDyslexic font asset

Place the verified OpenDyslexic regular font file here as:

`app/src/main/assets/fonts/OpenDyslexic-Regular.otf`

Before bundling or redistributing it, verify the exact release's license and preserve its copyright and license notices. The app currently falls back to the Android default typeface until the font asset is added. See the project README for the official font links and attribution.
